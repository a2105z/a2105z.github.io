# Aarav Mittal — Portfolio

Navy software-engineering recruiting site for [a2105z.github.io](https://a2105z.github.io/).

Built from a React + Vite + Tailwind template, filled with Aarav’s experience and projects — **Chronos** front and center, plus TeXForm, Meridian, Cosmos, and CoolGames.

## Develop

```bash
npm install
npm run dev
```

## Deploy (GitHub Pages)

```bash
npm run build
```

Push `dist/` via the existing Pages workflow, or use `gh-pages` / Actions as configured in `.github/workflows/deploy.yml`.
